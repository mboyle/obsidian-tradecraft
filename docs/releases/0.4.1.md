# Tradecraft 0.4.1

Tradecraft 0.4.1 is a community-review compatibility and type-safety update.

## Improvements

- Replace unsafe frontmatter and settings-data access with runtime-narrowed values.
- Use Obsidian's window-aware DOM helpers throughout linked references, the Daily Timeline, and the mobile week navigator.
- Preserve caret placement on older iOS versions without directly calling a deprecated browser API.
- Make asynchronous backlink refresh callbacks explicit and remove redundant type assertions.
- Enforce the reviewed TypeScript safety rules on all source code in continuous integration.

Tradecraft runs locally inside Obsidian, makes no network requests, and supports Obsidian 1.7.2 and later.
