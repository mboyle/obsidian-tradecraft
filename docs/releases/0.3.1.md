# Tradecraft 0.3.1

This compatibility release prepares Tradecraft for Obsidian Community Plugins review.

## Changes

- Replaced a regular-expression lookbehind so inline timeline editing works on older iOS versions supported by Obsidian.
- Replaced direct style assignments in the week navigator with Obsidian's CSS helpers.
- Limited timeline link suggestions to Markdown files while retaining vault-wide note completion.
- Added the official Obsidian plugin lint rules to local verification.
- Added cryptographic provenance attestations for every GitHub release asset.

## Privacy

Tradecraft runs entirely inside Obsidian. It makes no network requests, collects no telemetry, and sends no vault content anywhere. It enumerates Markdown paths and cached metadata to provide backlinks and editor suggestions.
