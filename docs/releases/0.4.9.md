## Fieldkit 0.4.9

Tradecraft is now Fieldkit. The repository has moved to [tradecraftso/fieldkit](https://github.com/tradecraftso/fieldkit), preserving its history and earlier releases.

- Update the plugin name, settings, notices, and release branding to Fieldkit.
- Keep the installed ID `tradecraft` so existing users retain their settings and update path.
- Request the community slug `fieldkit` through Obsidian; this requires administrator coordination and is not part of this release.

Existing users do not need to rename the plugin folder or reinstall for this release.
