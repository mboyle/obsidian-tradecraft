## Tradecraft 0.4.4

This release focuses on Obsidian community-review compatibility and keeps the existing Tradecraft experience intact.

- Removes unsupported and performance-sensitive CSS patterns, including `:has()`, `!important`, and partially supported text-decoration sub-properties.
- Preserves timeline focus and today indicators with broadly supported theme-aware styling.
- Adds searchable settings definitions for Obsidian 1.13 and newer while retaining compatibility with the declared minimum app version.
- Adds a typed boundary around Obsidian's Moment runtime to prevent unsafe values from propagating through Daily Note date handling.
- Keeps the production manifest, package metadata, and compatibility map aligned at version 0.4.4.
