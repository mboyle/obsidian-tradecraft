# Tradecraft 0.3.2

This compatibility release resolves an Obsidian Community Plugins validator false positive.

## Changes

- Separated the settings host's Tradecraft-specific type from Obsidian's base `Plugin` type.
- Prevented Tradecraft's own `settings` field from being mistaken for the newer `Plugin.settings` API.
- Re-enabled `obsidianmd/no-unsupported-api` in local verification so declared-version compatibility is checked before every release.

Tradecraft continues to support Obsidian 1.7.2 and later.
