# Tradecraft 0.4.0

Tradecraft 0.4.0 is the Community Plugins submission release, combining contextual linked references with focused Daily Note workflows across desktop and mobile.

## Highlights

- Read linked references as rendered, navigable context beneath the current note.
- Display Daily Note filenames as human-readable dates without renaming files or changing links.
- Navigate Daily Notes from a compact mobile week bar without creating empty notes while browsing.
- Read and edit consecutive Daily Notes in a continuous desktop timeline.
- Edit timeline notes with Live Preview-style formatting, wiki-link, tag, heading, block, and slash-command completion.
- Verify release assets with GitHub artifact attestations generated from the tagged source.

Tradecraft runs locally inside Obsidian, makes no network requests, and supports Obsidian 1.7.2 and later.
