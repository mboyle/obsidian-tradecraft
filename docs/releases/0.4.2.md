# Tradecraft 0.4.2

Tradecraft 0.4.2 establishes `tradecraft` as the plugin's permanent public ID before its first Community Plugins submission.

## Improvements

- Align the manifest ID, Community Plugins submission metadata, and manual installation directory with the Tradecraft name.
- Preserve the existing feature set and Obsidian 1.7.2 compatibility.

Existing manual installations should move the plugin folder from `.obsidian/plugins/dossier/` to `.obsidian/plugins/tradecraft/` and replace `dossier` with `tradecraft` in `.obsidian/community-plugins.json`.
