# Tradecraft 0.3.0

Tradecraft's first public release brings contextual backlinks and focused Daily Note workflows together in one local-first Obsidian plugin.

## Highlights

- Read linked references as rendered, navigable excerpts beneath the current note on desktop and mobile.
- Display Daily Note filenames as human-readable dates without renaming files or changing links.
- Navigate Daily Notes from a compact seven-day bar on mobile and narrow windows.
- Browse missing dates without creating empty files; a note is committed only after a meaningful edit.
- Use the desktop Daily Timeline to read and edit consecutive Daily Notes in one continuous view.
- Edit timeline notes with Live Preview-style formatting, wiki-link, heading, block, tag, and slash-command completion, rich paste and drop, search, familiar keybindings, autosave, and conflict protection.

## Privacy

Tradecraft runs entirely inside Obsidian. It makes no network requests, collects no telemetry, and sends no vault content anywhere.
